# Sorare Player Analytics Dashboard

Interactive Gradio dashboard for exploring the football player analysis outputs generated by the Sorare pipeline.

## Purpose

The dashboard loads CSV artifacts from the project-level `outputs/` folder and provides production-style exploration for:

- best players and rankings by position
- player score metrics and percentile profiles
- model feature importance and correlations
- overperformers, underperformers, and residual analysis
- statistical outliers
- age and height context
- Transfermarkt matching quality and unmatched players
- filtered dataset and player-report exports

Missing files are shown as warnings in the UI. The app continues running with whichever datasets are available.

## Dependencies

Install the dashboard dependencies from the project root:

```bash
pip install -r dashboard/requirements.txt
```

The root project may already include some of these packages. `shap`, `matplotlib`, `seaborn`, `scikit-learn`, and `scipy` are included for compatibility with the broader analysis workflow and future chart extensions.

## Expected Outputs

The dashboard looks for these files in `outputs/`:

```text
outputs/final_player_analysis_dataset.csv
outputs/player_rankings.csv
outputs/best_players.csv
outputs/feature_importance.csv
outputs/overperformers.csv
outputs/underperformers.csv
outputs/outliers.csv
outputs/unmatched_transfermarkt_players.csv
```

It also uses these optional files when available:

```text
outputs/shap_importance.csv
outputs/score_correlations.csv
```

## Run

From the Sorare project root:

```bash
python dashboard/app.py
```

Gradio will print a local URL, usually `http://127.0.0.1:7860`.

To request a temporary public Gradio link:

```bash
python dashboard/launch_share.py
```

The public link is temporary and only works while the process is running on your machine.

## Performance

Only the Overview tab loads automatically. The heavier analysis tabs use explicit update buttons so the browser does not render every chart at startup.

## Tabs

- **Overview**: KPI cards, summary table, score, age, and position distributions.
- **Player Rankings**: searchable rankings, metric selector, radar chart, percentiles, and two-player comparison.
- **Feature Importance**: model importance, SHAP importance when available, heatmap, and correlation rankings.
- **Overperformers & Underperformers**: expected vs actual scores, residuals, ranking bars, and team residual summaries.
- **Outliers**: outlier table, scatterplot, boxplot, and interpretation guide.
- **Player Profile**: detailed player explorer with radar, percentile, and comparison visuals.
- **Transfermarkt Data Quality**: matched/unmatched summary, confidence distribution, duplicate diagnostics.
- **Export**: filtered dataset and player report CSV downloads.

## Troubleshooting

- **Dashboard starts but shows warnings**: one or more expected files are missing from `outputs/`. Regenerate the analysis pipeline or use the available tabs with partial data.
- **Charts are empty**: the selected dataset may not contain the required columns for that chart. The app shows an empty-state message instead of crashing.
- **`ModuleNotFoundError`**: install dependencies with `pip install -r dashboard/requirements.txt`.
- **Encoding looks odd for some names**: source CSVs may contain mojibake from earlier exports. Fix the upstream encoding and regenerate outputs for clean display.
- **Port already in use**: set a different port with `SORARE_DASHBOARD_PORT`, for example `set SORARE_DASHBOARD_PORT=7862`.
